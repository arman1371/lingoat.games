# App icon and favicon

The icon is a simplified head of Goaty (the mascot) on the brand purple (`color/brand/primary`, `#584BCA`).
The design lives in the Penpot file "LingoatGames", page **App icon**; the small versions drop ears and beard so the
head stays readable at 16 and 32 px.

| File (in `public/`)              | Use                                                               |
| -------------------------------- | ----------------------------------------------------------------- |
| `favicon.svg`                    | browser tab (modern browsers), simplified head                    |
| `favicon.ico`                    | 16, 32 and 48 px fallback (PNG inside)                            |
| `apple-touch-icon.png`           | iOS home screen, 180 px, full bleed (iOS rounds it)               |
| `icons/icon-192.png`, `-512.png` | manifest icons, purpose `any`, rounded corners                    |
| `icons/icon-maskable-512.png`    | manifest icon, purpose `maskable`, head inside the 80 % safe zone |
| `icons/icon-monochrome-512.png`  | manifest icon, purpose `monochrome`, for themed icons             |

All of them are generated by `scripts/icons/build.mjs` from the SVG definitions in `scripts/icons/goaty.mjs`
(`npm run icons`, uses Playwright's Chromium; set `PW_CHROMIUM_PATH` in the sandbox). Change the design in Penpot first,
mirror it in `goaty.mjs`, run `npm run icons` and commit the generated files.

Installed Android apps may keep the old icon until the app is reinstalled.
